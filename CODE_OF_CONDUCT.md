# Code of Conduct

## Our standards

This project aims to be a respectful, inclusive and professional space.

Examples of expected behavior:

- Use welcoming and respectful language.
- Accept constructive feedback gracefully.
- Focus on what is best for the project.
- Show empathy toward other contributors.

Examples of unacceptable behavior:

- Harassment or discriminatory language.
- Personal attacks.
- Public disclosure of private information.
- Disruptive or intentionally unproductive behavior.

## Enforcement

Project maintainers may remove comments, close issues or reject contributions that do not follow this code of conduct.
